COMMIT 1/6 — fix: optional host permission
Files:
  src/options/options.js
  src/background/service-worker.js
  src/shared/defaults.js
  manifest.json
Command:
  git add src/options/options.js src/background/service-worker.js src/shared/defaults.js manifest.json
  git commit -m "fix: optional host permission"
Changes:
  The options page requested the literal <all_urls> pattern while manifest.json declares the
  wildcard host pattern, so Chrome answered "Only permissions specified in the manifest may be
  requested" (an unhandled promise rejection) and the permission never became granted.
  The service worker checked the same wrong pattern, so "all sites" and custom-site injection
  silently did nothing.
    * one pattern constant per context (ALL_ORIGINS = ["*://*/*"]) used for request(),
      contains() and registerContentScripts();
    * permissions.request() is now the first awaited call in the gesture handler (awaiting
      anything else makes Chrome drop the user gesture);
    * rejections are caught and the warning under the switch reflects the real state;
    * the service worker re-registers dynamic scripts on chrome.permissions.onAdded.

COMMIT 2/6 — fix: rtl per block
Files:
  src/content/bidi.js
  src/content/entry.js
  src/content/rules.js
  styles/parsi-chin.css
  src/popup/popup.js
Command:
  git add src/content/bidi.js src/content/entry.js src/content/rules.js styles/parsi-chin.css src/popup/popup.js
  git commit -m "fix: rtl per block"
Changes:
  Direction is decided once per block from content statistics instead of dir="auto" (which
  resolves from the first strong character only) and unicode-bidi: plaintext (which resolved
  per line). Persian-dominant = ratio >= 0.5, or >= 0.25 with a real Persian word.
  Digits/ZWNJ/ZWJ/LRM/RLM no longer count as letters; list containers are flipped with their
  items; English content inside an RTL block is pinned back to LTR; .pc-rtl/.pc-ltr carry the
  !important rules so a site's own direction CSS cannot win; long paragraphs are processed.
